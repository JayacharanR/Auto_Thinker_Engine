# Paired active-bulb label audit, before fitting

The existing signal corpus has native RGB phase pairs and responsive housings.
Housing centers can fall on dark plastic; a whole-housing class target also
labels inactive bulbs and dark pixels. Audit a different training target before
spending compute on another detector. This audit fits no model and changes no
driving input, reward, evaluation suite or qualification gate.

Use only the successful static v2 corpus and its audited TRAIN supplement.
Recheck source, case, geometry and image hashes and original capture receipts.
Intersect original TRAIN roles with the current actual-geography guard, reserved
M3 rule locations, both new M5 calibration locations and the original four
component-validation junctions. Verify each retained static ego pose against the
original map bytes and one-metre forbidden-junction clearance, conservatively
subtracting the measured final static positional drift (physics was disabled). No native server.
Preserve all 144 original validation images and 72 known-label denominator;
do not derive validation pixel labels or inspect new model outcomes in this audit.

For each already responsive TRAIN housing, cast RGB to float before differences.
Per pixel use mean-channel brightness of min(red, red-repeat), yellow and green.
A phase pixel must exceed the brighter of both other phases by at least
max(20 RGB levels, five times mean absolute red/red-repeat difference).
This fixed threshold is registered before computing coverage. Yellow also
requires the original yellow-support flag. No response remains unknown. Dark
housing pixels are ignored, not background. Geometry/paired phases are offline
label construction only; a future student sees a single current RGB image.

Report every included and excluded case with the reason, phase masks, number of
responsive labels with/without target pixels, and per-location/class support.
No threshold search or automatic fit. Show the first eligible housing in sorted
source/town/case/view order for each training location, with all four phases and
fixed-mask overlays. Preserve failures and do not cherry-pick examples.

Maximum 600 seconds and 100 MB new artifacts, original shared storage guardian
and baseline; STOP supported. Outputs are a prospective training-label diagnostic,
not detection accuracy, driving evidence, or proof of signal applicability.
Original component validation has been inspected in earlier experiments; retain
that limitation. A later fit requires its own prospective comparison/selection
protocol and must keep unknown housings in the existing evaluation denominator.
